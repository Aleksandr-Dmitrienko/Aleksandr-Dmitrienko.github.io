# Персональный сайт — Aleksandr Dmitrienko

Статический сайт для заявок на комнату в WG в Цюрихе. Английская и немецкая версии.
Ноль зависимостей, ноль JavaScript, ноль сборки. Открывается как обычные файлы.

## Структура

```
index.html          английская версия
de/index.html       немецкая версия
assets/style.css    все стили (один файл)
assets/img/         подготовленные фотографии
assets/favicon.svg
assets/apple-touch-icon.png
photo/              исходники (на сервер не заливать)
```

## Перед публикацией — обязательно

**Домен.** Заменить `https://aleksandr-dmitrienko.com` на реальный адрес.
В `index.html` и `de/index.html` — по 7 вхождений в каждом (canonical, hreflang, og:url, og:image).

Без этого не будет работать превью ссылки в WhatsApp и Telegram:
`og:image` обязан быть абсолютным URL.

Это единственное, что осталось незаполненным. LinkedIn, почта и WhatsApp уже вписаны.

## Про телефон на странице

Номер стоит в блоке контактов как ссылка на WhatsApp (`wa.me`). Он виден в исходном
коде страницы, а значит доступен спам-ботам, которые обходят сайты. Для поиска,
который идёт два-три месяца, это приемлемая цена за низкий порог связаться.

**Убрать номер, когда комната найдена** — достаточно удалить одну строку `<a href="https://wa.me/...">`
в обоих файлах. И заменить на швейцарский номер, когда он появится.

## Как править текст

Открыть `index.html` в любом редакторе, найти нужный абзац, поменять.
Немецкую версию править отдельно — это не автоперевод, а самостоятельный текст.

Апостроф пишется как `&rsquo;`, длинное тире как `&mdash;`.

**Дата въезда** встречается в четырёх местах каждого файла: `<meta name="description">`,
`og:description`, подзаголовок в `<header>` и первый пункт списка «The practical part».
Менять во всех четырёх.

## Как заменить фотографию

Положить новый файл в `photo/` и пересобрать. Из PowerShell в корне проекта:

```powershell
Add-Type -AssemblyName PresentationCore, WindowsBase
$src = "photo\НОВЫЙ_ФАЙЛ.JPG"; $name = "portrait"   # имя без -800/-1600
$s = [IO.File]::OpenRead((Resolve-Path $src))
$dec = [System.Windows.Media.Imaging.BitmapDecoder]::Create($s,'None','OnLoad')
$img = [System.Windows.Media.Imaging.BitmapSource]$dec.Frames[0]
$o = 1; try { $v = $dec.Frames[0].Metadata.GetQuery('/app1/ifd/{ushort=274}'); if($v){ $o = [int]$v } } catch {}
$sx=1; $rot=0
switch($o){ 2{$sx=-1} 3{$rot=180} 5{$sx=-1;$rot=270} 6{$rot=90} 7{$sx=-1;$rot=90} 8{$rot=270} }
if($sx -ne 1){ $img = New-Object System.Windows.Media.Imaging.TransformedBitmap($img,(New-Object System.Windows.Media.ScaleTransform($sx,1))) }
if($rot -ne 0){ $img = New-Object System.Windows.Media.Imaging.TransformedBitmap($img,(New-Object System.Windows.Media.RotateTransform($rot))) }
foreach($w in @(800,1600)){
  if($w -gt $img.PixelWidth){ continue }
  $t = New-Object System.Windows.Media.Imaging.TransformedBitmap($img,(New-Object System.Windows.Media.ScaleTransform(($w/$img.PixelWidth),($w/$img.PixelWidth))))
  $e = New-Object System.Windows.Media.Imaging.JpegBitmapEncoder; $e.QualityLevel = 84
  $e.Frames.Add([System.Windows.Media.Imaging.BitmapFrame]::Create($t))
  $f = [IO.File]::Create((Join-Path (Get-Location) "assets\img\$name-$w.jpg")); $e.Save($f); $f.Close()
  "$name-$w.jpg  $($t.PixelWidth)x$($t.PixelHeight)"
}
$s.Close()
```

Скрипт печатает итоговые размеры — **их надо вписать в `width` и `height`** у соответствующего
`<img>` в обоих HTML. Если этого не сделать, при загрузке страницы текст будет прыгать.

`.HEIC` обрабатывается так же, как `.JPG` — отдельная конвертация не нужна.

## Локальный просмотр

**Просто открой `index.html` двойным кликом.** Все пути относительные, поэтому сайт
полностью работает с диска — со стилями, фотографиями и переключателем языка.

Если хочется посмотреть по «настоящему» адресу (например, чтобы проверить, как
выглядит `/de/` без `index.html` в конце), можно поднять сервер:

```bash
node .claude/serve.js .
```

Потом открыть http://localhost:4321.

## Публикация

Подойдёт любой статический хостинг. Проще всего — **Cloudflare Pages** или **Netlify**:
перетащить папку проекта в веб-интерфейс, получить адрес, привязать домен.
Сборка не нужна, build command оставить пустым, output directory — корень.

Папку `photo/` перед заливкой лучше удалить или исключить: это исходники на 60 МБ,
и они не используются сайтом.

После публикации проверить превью ссылки:
- Telegram — отправить ссылку самому себе
- WhatsApp — то же самое
- https://www.opengraph.xyz — показывает, что увидят остальные

## Что обновить позже

- **Дата въезда**, если сдвинется виза (четыре места в каждом файле).
- **Фото из лаборатории** — когда начнёшь в UZH. Ставить после абзаца про работу в лаборатории.
- **Фото с людьми** — если появятся, это самая ценная правка из возможных.
- **Немецкий** — когда пройдёшь курс, убрать абзац «Diese Seite wurde für mich übersetzt»
  в конце `de/index.html`.

## Решения, которые уже приняты (чтобы не переделывать случайно)

- **Все пути относительные** (`assets/...` в корне, `../assets/...` в `de/`).
  Благодаря этому сайт одинаково работает при открытии файла с диска, с локального
  сервера и на любом хостинге, в том числе в подпапке. Не менять на пути от корня (`/assets/...`) —
  тогда открытие двойным кликом сломается.
- **Нет автоопределения языка.** Переключатель ручной. Автоматический редирект ломает
  расшаренные ссылки: человек отправляет `/de/`, получатель видит `/en/`.
- **Нет анимаций.** Появление картинок по скроллу было — убрано: при быстрой прокрутке
  на телефоне картинки на полсекунды оставались пустыми.
- **Один шрифт на весь сайт.** Пара «антиква + гротеск» — самый узнаваемый признак шаблона.
- **Фотографии не приведены к единому цвету.** Разница в свете доказывает, что снимки
  настоящие и сделаны в разные годы. Объединяет их одинаковая ширина, отступы и подписи.
- **Светлая тема без тёмной.** Сайт читают один раз с телефона; переключение не нужно.
